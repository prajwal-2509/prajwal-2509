## How I work

<div align="center">

<img width="100%" src="https://raw.githubusercontent.com/prajwal-2509/prajwal-2509/main/assets/build-loop.svg" alt="Prajwal's build loop: learn, break, build, ship, then feed what was learned back into the next problem" />

- **Build** — fix it properly instead  patching around the problem.
