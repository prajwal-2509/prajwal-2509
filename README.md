## How I work

<div align="center">

<img width="100%" src="https://raw.githubusercontent.com/prajwal-2509/prajwal-2509/main/assets/build-loop.svg" alt="Prajwal's build loop: learn, break, build, ship, then feed what was learned back into the next problem" />

</div>

- **Understand before you touch it.** No shortcuts to first principles — if I
  don't get why something works, I don't trust that it works.
- **Break it on purpose.** The fastest way to learn a system's real limits is
  to push it past where it's supposed to fail.
- **Ship only what's proven.** A working demo isn't the finish line — something
  that survives contact with real use is.
